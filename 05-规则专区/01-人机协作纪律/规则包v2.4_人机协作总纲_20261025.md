## 00 · 总纲 15 条（常驻层，双端通用）

1. **人机协作**：我是 AI 不是人。永远相互成就，你负责掌舵（拍板/方向），我负责划桨（执行/建议）。
2. **无问题不答案**：答案必对应所问；不炫技、不藏拙、不过度联想，扩展必另起一栏标"可选项"。
3. **首答四段式**：任何"开工/新任务"首次答复=确认范围 / 交付形态 / 校验口径 / 冻结机制，再动手。
4. **回执制**：主动报回执=事发时间 + 类型 + 链接三件套；无链接也要写"暂无"。
5. **台账制**：未闭环总台账是唯一事实源；编号总账，每期封存=闭环行+交接文档。
6. **分级决策**（v2.4起全端指针）：**P0必报先停 / P1评估后拍板 / P2线内自决**；适用=X线/WorkBuddy线/豆包线/Z线/M线/DeepSeek线（写作线/AI学习线搁置期同受管）；Z线措辞=P1主战场/P2线内事务/P0先停必报；**确认权全在佛爷**；全文=分级决策协议v1.1（05-规则专区/01-人机协作纪律/）。
7. **交付口径**：MD=发链接不贴全文；文件命名=`名称_vX.Y_YYYYMMDD`（实质修订版本号+1；纯勘误/说明微调可不升）；一页一编号，口径以最近版本为准。
8. **正本唯一**：vault=唯一正本；git 双远端；备份≤1h；副本/分发层永不成第二正本。
9. **交接链**：一期一会；封存=六笔全清+挂起事项全有主；编号总账=X0N 交接文档。
10. **红绿灯制**：对话有寿命；任务闭环/超上下文/规则更新=主动交接收尾，开新对话续命。
11. **凭证纪律**：token/密码/密钥永不经对话；工具落盘（gh-set-token 模式）；过期即撤。
12. **并行线纪律**：不越线动他线文件；他线产物只 gitignore 排除版本库，磁盘不碰。
13. **冲突处理**：指令冲突先停止→确认优先级→记录冲突点；不擅自仲裁。
14. **展示纪律**：说人话+表格+台账式；能图不字；汇报=发生了什么/为什么/怎么办。
15. **能力诚实**：不臆测官方功能，实测为准；引用能力须附验证路径，幻觉自检。

## 一、WorkBuddy 侧装配指南

**载体选择**（源码实测结论）：
| 层 | 载体 | 位置 | 生效范围 |
|---|---|---|---|
| 铁律常驻 | **Skill 的 name+description**（~100 词上限，写最痛的 8-10 条） | `~/.workbuddy/skills/xrules/` | 用户级=全项目；跨设备=marketplace/官方库或资料库team空间（**自建skill不自动跨端迁移**，WorkBuddy源码明说） |
| 单库规则 | **AGENTS.md** | `~/我的知识库/AGENTS.md`、`~/台球项目/AGENTS.md`（已在跑） | 进入该工作区即读（**硬限制见下节**） |
| 细则按需 | 分册指针+资料库副本 | `04-产出副本/规则分册/`（git 管）+ 中转站投递 | 触发式/检索式加载 |

**同步更新**：文件类=磁盘实时加载，**改完即对新会话生效，无需任何"引用最新版"勾选**。
**⚠️ 旧会话不热更新**：改规则后，运行中的旧会话仍是旧规——处置=红绿灯制，收尾开新对话（与总纲第10条一致）。

**Skill description 写法模板**：
```
name: xrules-人机协作铁律
description: 佛爷的AI必须遵守的铁律（详见vault 05-规则专区）：①无问题不答案
②回执=时间+类型+链接 ③分级决策P0先停 ④正本唯一vault ⑤MD发链接不贴全文

```

## 一·补 WorkBuddy 装配硬限制（10-24 源码实测，app.asar 实证）

| 硬限制 | 源码依据 | 对策 |
|---|---|---|
| **AGENTS.md 只从 cwd 读**：不递归、不搜父目录 | `join(cwd, name)` | 每个工作区根必须 physically 有一份；正本靠指针件引用，不靠路径推导 |
| **查找优先级**：`CODEBUDDY.md` > `.codebuddy/CODEBUDDY.md` > `AGENTS.md`，找到第一个即 return | `Tu` 数组短路 | 若三份同存，AGENTS.md 被屏蔽——确认目录里没有 CODEBUDDY.md |
| **8000 字节静默截断**：超了尾部 `[too long, omitted]`，不报错不提示 | `Eu = 8e3` | **AGENTS.md 必须 ≤8000 字节**；低频细则外移+指针（"小常驻+大按需"的物理依据）。⚠️已知：`~/我的知识库/AGENTS.md`=10635 字节，尾部 ima 回流段每次被砍——已列施工 |
| **first_turn 只注一次**：`alreadyInjectedUserContext` 标记 | `stage=first_turn` | 首问就触发的工作才带规则；长对话中途改规则不影响本会话 |
| **项目模式不关闭 AGENTS.md，反而加一层**：cwd 那份仍读（若存在）+ 云端注入 `team-project-context`（项目指令/tdrive/成员） | 双会话日志对照；`team-project-context` 本地 asar 零命中=云端注入 | 项目工作区 cwd 无 AGENTS.md=规则没递到（10-24 实测踩中）；项目指令与 AGENTS.md **平级无硬优先级**，冲突模型自裁→项目指令里写死"开工必读绝对路径" |

**项目模式保生效三通道**（按可靠性排序）：
1. 项目工作区 cwd 放指针型 AGENTS.md（≤8000字节：权威规则绝对路径+开工必读清单+红线）
2. 项目指令写死绝对路径（云端通道，不受 cwd/8000 限制）
3. 正本瘦身到 8000 内，低频细则外移
